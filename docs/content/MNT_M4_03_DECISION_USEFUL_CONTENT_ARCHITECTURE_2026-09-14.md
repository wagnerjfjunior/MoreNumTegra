# MNT-M4-03 — Decision-Useful Content Architecture

Status: `IN_PROGRESS / AUTHORIZED`

Execution base: merged MNT-M4-02 main SHA `54d391c018122b2d42afba176c343d94fbcd8f5f`.

Purpose: define what decision-useful content each governed page type must contain before runtime implementation.

Initial principles:
- content must answer real buyer questions, not exist only for keyword coverage;
- exact-project pages prioritize identity, location, stage, typologies, differentiators, factual commercial state and next action;
- master pages explain the development and route users to child projects without stealing exact-project intent;
- stage/location pages require factual membership and must route to exact-project owners;
- historical/sold pages must separate historical truth from current exception inventory;
- FAQs must be visible and factual before FAQPage schema is considered;
- no unsupported price, metragem, address, availability or differentiator may be invented;
- Form 46 and current CTA journey remain unchanged by this task.

No HTML/CSS/JS implementation, schema implementation, canonical/redirect/sitemap mutation, Green/Vercel/Search Console mutation, Ads or spend is authorized by M4-03.
